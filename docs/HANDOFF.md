- **Musical Drafts (P22-01, D-029):** `draft Name(n1..n4) [reverse Inverse]` and `weave Draft on Target` compile to a draft table and the `weave` opcode; `VM.weave_notes` resolves played notes (forward or declared reverse) to `Weave(caster, draft, target)` handlers; in-script weaves queue in `VM.pending_weaves` until `dispatch_pending_weaves`; unmatched weaves record `WeaveFizzled`.

**Gotchas for the next session**
- Zig 0.17 (P37-01): there is no `@cImport`; `build.zig` translates `src/display/sdl.h` into the `sdl` module, and every native module that reaches the renderer imports it (wasm modules do not; the renderer names `sdl` only off freestanding). Array repetition (`**`) is gone (use `@splat`), `b.args` is `addPassthruArgs()`, `pathFromRoot` is `b.root.joinString`, and `@typeInfo` enums and structs list `field_names` and `field_values` / `field_types` (prefer `std.meta.tags` and `stringToEnum`). Native builds keep `use_llvm = true` (the self-hosted linker cannot link SDL2).
- Render goldens (P32-02a): `proofs/golden/render.txt` holds one pixel hash per proof scene, drawn offscreen by SDL's software rasterizer. P32-02b left every hash unchanged; later presentation work must too. A mismatch writes `.actual.bmp` images beside the golden. The message band (D-099, D-123) grows upward from y 582 at 1280x720 to a top of 504 with four rows and the command bar, so proof art, marks, and labels must stay above that line; the Observatory's plan was lifted for exactly this reason. A name or prompt lifted above its mark stays above: when another label holds the air there, the resolver climbs a tier rather than drop it back under the band (D-124). A prop with no art is a 32-pixel marker centred on its hotspot, so a prop's whole marker clears 504 only from world y 9 down. The proof render test enforces the line for every scene and progress state (`check_band` in `proofs/render_golden_test.zig`): it clears the log, records every string the frame draws, and fails on a mark's circle, a prop's default marker, or a drawn string in rows 504 to 582. Each scene is staged through its proof's own host layout (`stage_host`, P43-01), so a new proof whose host places marks, props, or cast starts in Zig needs an entry there; The Well of Three Tides needs none because its script declares every mark and prop. Prop art is measured by the rectangles, lines, circles, and sprites the frame drew (`Canvas.RectProbe`, P43-02), tagged with a `RectKind` layer; `check_band` fails on a `.prop` draw in the band and skips `.backdrop`, `.chrome`, and `.overlay`. Marks and people are measured by their drawn boxes too (Q-013): the Observatory's six working-floor marks and The Living Village's cottages mark sit at world y 8, one unit above their row, so a mark disc ends on row 492 and a person on 494, while their props stay on the row at y 9. Every staged frame is drawn again at 1920x1080 in a second window and the band is checked there against that render's probes (P43-03); only 1280x720 is hashed. 640x360 cannot be checked, because its band top is row 144 while world y 0 draws at row 200 (Q-014).

Use `SpatialSystem.walk_to_with_world` to honor locks; bare `walk_to` is the lock-free graph-only convenience. The VM's walking opcode uses the world-aware form. Locks are read at walk planning and do not interrupt an in-flight path. Path initializers can also assert `Trapped` or `PortalBlocked`; `can_access_portal` reads those current facts.
- Dialogue (D-046): `choice` blocks suspend the fiber. Select with `VM.choose` or `host.Session.choose_dialogue`; the latter advances one tick so the chosen body speaks. `RenderFrame.dialogue` is the presentation channel, and `VM.set_dialogue_speaker(owner, npc)` makes an NPC the visible speaker while options stay keyed by the fiber owner. The filter limits the graph and states list only; dialogue and "Next to Happen" ignore it. Neighbours past the ring's 16 slots are unreachable by keys unless a filter narrows the ring. `state_graph` is exported as `bespoke.display.state_graph` for the render golden.
- Temporal action routing (D-049): use `Session.active_world` for host actions while a hypervisor branch is active. `Session.refresh`, restore, and advance bind the VM to that arena. After advancing the hypervisor directly, call `Session.sync_active_world` before any further VM operation; `refresh` also performs the binding.
- Proofs live in `proofs/` and import the engine as `@import("bespoke")`; they cannot be compiled with a bare `zig test`. Use `zig build test-proofs` and `zig build run-proof -- --<proof>`. The Saltmarket selector is a generated dialogue: click an option or press `1` to `3`; the proof has no wasm or render golden yet.

- Branch worlds (D-027, D-044): the keystone must reach the convergence waypoint, with `LoopClosed` (or `ConvergenceReady`) asserted, before `collapse_budget_ticks` runs out; otherwise the branch is discarded (`.budget_expired`; the proof's status calls it `singularity_collapsed`) and the player rewinds. Unidirectional DAG temporal causality in DOTT scenarios cascades forward from past to future; rewinding snapshots restores all three eras synchronously without paradox loops.
- Procedural audio runs asynchronously via the SDL2 audio callback; communication with the simulation spine must remain strictly decoupled through `AudioBridge` ring buffer queueing (D-001, D-019). Scene names containing "Bell Tower" are matched first in `get_track_for_scene` and the renderer theme chain, ahead of "Sanctuary" and "Courtyard".
- `VM.step_tick` clears `emitted_cues` at the start of every tick; read speech after the tick with `host.SpeechLog` or `host.speech_this_tick` (D-033). The per-proof readers that took a stale index are gone.
- Headless scenario runs wait on stdin after printing SUCCESS; run them with `</dev/null` in scripts or they hang until killed.
- Command bar (P26-03): off unless a host calls `window.enable_command_bar(true)`; refresh `window.command_words` with `host.command_words` after ticks. While focused it eats every key. In a one-room scene every prop is in scope, so check position before `dispatch_command` (see the observatory's `refusal`). Speech in windows: the window draws no script `say` line by itself. A proof must read `host.speech_this_tick` after every tick (actions and `tick_due`) and show it, as the observatory's `Play.advance` and the fire escape's `show_speech` do. Observatory (P33-03): an interception resolves the agenda inside the tick, but the `Intercepts` handler speaks on the next tick; the proof's `encounter` helper waits one extra tick. The script's `LarkspurPlan` grid exists only to place the 12 marks (no cell attributes), so render staging sees the real floor plan; the host adds two stairs to the compiler's chain. Grid proof (P25-03): the host's door rules in `proofs/grid_puzzle.zig` exist because scripts cannot read cells. `proofs/art.zig` repeats the gallery's size (`GALLERY_CELLS`, `GALLERY_CELL_SIZE`); a layout test pins them to the script. The render golden seeds grid layouts (only grids) before drawing.
- Grids (D-054, D-055): cells are addressed by index only (no DSL coordinate queries yet). `grid.seed` runs every `host.tick` but returns after one marker scan. Fire timers are fact TTLs: never remember `CellBurning` without the declared `burn` lifetime (use `grid.ignite`), or the fire becomes permanent. Hazard states lag the cell change by one tick. `place` rewrites a mark's position and every incident edge cost to Euclidean distance. Script origins are non-negative (the lexer has no negative literals); the Zig API accepts negative origins. Liquid is presence only, with no depth.
- `--test-filter` on `src/root.zig` runs 0 tests (the filter drops the named import test). Filter through `src/package.zig`, which imports the compiler, draft, and save modules.

- Arrival rules (D-036): a host must call `vm.load_compiled_rules(&compiled)` or no `when` rule fires (the goat proof did not call it before P32-18). Placing an actor with `transition_actor` is not an arrival; a walk to the mark the actor stands on is. `.bspk` is format version 6 after D-051.
- Dialogue duel is `src/duel.zig` (D-035). Call `Duel.init` before the first snapshot: it asserts the `Counters` and `VariantOf` knowledge base as facts. The script declares `win 3`.
- Script declarations (D-045, D-050) live in `compiled.societies`, `compiled.duels`, and `compiled.degradations`; multiple declarations are preserved in source order. They borrow interned World text, so the World must outlive the compiled program. Container declarations run automatically through `host.tick`; society and duel declarations remain explicitly selected by their proof hosts. Path selection (P24-01) is one-way; path routines share the top-level namespace and halt when inactive.
- Waypoint locks (P24-02, D-053): `WaypointBlocked` is a unary fact on the mark entity whose name matches the waypoint. Use `SpatialSystem.walk_to_with_world` to honor locks; bare `walk_to` is the lock-free graph-only convenience. The VM's walking opcode uses the world-aware form. Locks are read at walk planning and do not interrupt an in-flight path. Path initializers can also assert `Trapped` or `PortalBlocked`; `can_access_portal` reads those current facts.
- Dialogue (D-046): `choice` blocks suspend the fiber. Select with `VM.choose` or `host.Session.choose_dialogue`; the latter advances one tick so the chosen body speaks. `RenderFrame.dialogue` is the presentation channel, and `VM.set_dialogue_speaker(owner, npc)` makes an NPC the visible speaker while options stay keyed by the fiber owner. A save made during an open set stores a `waiting_dialogue` fiber (save tag 6); `VM.sync_dialogue` releases it when the restored world has no matching set.
- Temporal action routing (D-049): use `Session.active_world` for host actions while a hypervisor branch is active. `Session.refresh`, restore, and advance bind the VM to that arena. After advancing the hypervisor directly, call `Session.sync_active_world` before any further VM operation; `refresh` also performs the binding.
- Proofs live in `proofs/` and import the engine as `@import("bespoke")`; they cannot be compiled with a bare `zig test`. Use `zig build test-proofs` and `zig build run-proof -- --<proof>`. The Atlantis selector is a generated dialogue: click an option or press `1` to `3`; the proof has no wasm or render golden yet.
- When restoring snapshots via `restore_state` or `SaveManager.load_slot`, the world memory buffer is rewound in place; external display layers should call `DisplayBridge.capture_frame()` immediately following a restore to synchronize visualization.
- Reactive rules are edge-triggered: they fire once when a condition transitions from false to true. The rule re-arms when the condition clears, preventing infinite interrupt loops while conditions remain active.
- In Tangent Universe scenarios, the Artifact of Metal must reach the designated vortex waypoint before `collapse_budget_ticks` expires; otherwise, a catastrophic black hole singularity occurs (`singularity_collapsed = true`), requiring time-travel rewind.
- Unidirectional DAG temporal causality in DOTT scenarios cascades forward from past to future; rewinding snapshots restores all three eras synchronously without paradox loops.
- Procedural audio runs asynchronously via the SDL2 audio callback; communication with the simulation spine must remain strictly decoupled through `AudioBridge` ring buffer queueing (D-001, D-019).
- `VM.step_tick` clears `emitted_cues` at the start of every tick; read speech after the tick with `host.SpeechLog` or `host.speech_this_tick` (D-033). The per-proof readers that took a stale index are gone.
- Scene names containing "Bell Tower" are matched first in `get_track_for_scene` and the renderer theme chain, ahead of "Sanctuary" and "Courtyard".
- Headless scenario runs wait on stdin after printing SUCCESS; run them with `</dev/null` in scripts or they hang until killed.
- `--test-filter` on `src/root.zig` runs 0 tests (the filter drops the named import test). Filter through `src/package.zig`, which imports the compiler, draft, and save modules.

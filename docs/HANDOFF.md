**Gotchas for the next session**
- When restoring snapshots via `restore_state` or `SaveManager.load_slot`, the world memory buffer is rewound in place; external display layers should call `DisplayBridge.capture_frame()` immediately following a restore to synchronize visualization.
- Reactive rules are edge-triggered: they fire once when a condition transitions from false to true. The rule re-arms when the condition clears, preventing infinite interrupt loops while conditions remain active.
- When stepping forward after scrubbing backward in time, subsequent future snapshots are pruned to record the newly divergent simulation timeline.
- The procedural audio synthesizer runs asynchronously in an OS audio thread via the SDL2 audio callback; communication with the simulation spine must remain strictly decoupled through `AudioBridge` event queueing to maintain lock-free, deterministic ticks (D-001, D-019).

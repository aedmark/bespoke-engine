# Changelog

User-visible changes to the BeSpoke Engine, newest first.

## Unreleased

- Added generic, script-declared container degradation (`P23-01`, `D-050`). Stable vessel entities now carry fact-backed contents, volume, damage stage, exposure deadline, and terminal failure waypoint; `host.tick` advances the lifecycle so snapshots and rewinds restore it completely. `.bspk` format version 5 carries degradation profiles and still loads versions 1 through 4.
- Temporal sessions now route VM execution, dialogue, display state, and gameplay actions through the active hypervisor branch (`P31-05`, `D-049`), returning to primary after resolution or expiry. Darko's interactive flood, letter, inventory, and vortex actions now satisfy the same branch loop-closure check used by the hypervisor.
- Temporal hypervisor state now saves and restores atomically with the world (`P31-04`, `D-048`). `.sav` version 2 adds a length-delimited branch envelope carrying the branch world, countdown, collapse state, teleology, and dream residue; version 1 saves stay readable by non-temporal loaders. Darko's scrub, rewind, quick-save, and load use the temporal session, so the countdown and active branch cannot desynchronize from the primary world.
- The public showcase site now runs the real embedded `bespoke-proofs.wasm` (`P30-01` partial). `tools/build_site.py` embeds the module and `tools/site_simulator.js` drives six proof decks through the `wasm_*` exports, with the same pointer, key, timeline, catalyst, and pause controls as the desktop proofs. The page remains a single self-contained file; its old JavaScript decks, fact list, action bank, and event stream are gone. Audio and the remaining three decks are open.
- Removed the embedded WebAssembly simulator deck and base64 payload from `docs/manual.html` in favor of the standalone interactive viewport on `site/index.html` (`D-047`). Rebuilding `docs/manual.html` no longer requires `zig build wasm-proofs`, and the manual's payload size is reduced from 1.8 MB to ~204 KB.
- Insult Sword Fighting is playable in the window (`P32-23`): `D` and `C` start duels against Pirate Bob and Carla, `1` through `5` answer the round's generated reply set, `T` exercises inquiry fatigue on the barkeep, and `W` advances 50 ticks. The script declares `win 3`, active rounds survive rewinds, and the headless golden is unchanged.
- Interactive dialogue can now run from script `choice` blocks (`P32-30`, `D-046`): the VM records the pruned options as World facts, suspends the fiber, and resumes at the selected body. Hosts can open the same lifecycle for runtime-generated choices with `VM.open_generated_dialogue` and resolve them with `VM.choose`; `RenderFrame.dialogue` and `Session.choose_dialogue` carry it to a window. Dialogue state survives snapshots and rewinds, and the GK3 Buthane conversation now runs through its script's choices with an unchanged golden.
- Scripts can declare complete emergent societies and dialogue duels (`P32-22`, `P32-24`, `D-045`). `society` blocks configure needs, rosters, roles, routines, places, friendships, and vocabulary; `duel` blocks configure challenge/reply pairs, tier variants and assignments, and inquiry-fatigue stages. The Living Village and Insult Sword Fighting now consume their script declarations instead of Zig configuration tables, with unchanged goldens.
- `.bspk` packages are now format version 4 and carry compiled society and duel declarations. Versions 1 through 3 still load with empty declaration tables (`D-045`).

### Fixed
- `SpatialSystem.walk_to` now turns an in-flight actor back toward the waypoint it just left and raises the normal arrival edge there (`P32-25`).
- The Spitting Contest and GK3 proof runners now send player intent through their DSL cue handlers instead of writing puzzle facts from Zig; their transcripts use the dialogue the scripts emit (`P32-26`).
- The WebAssembly module no longer faults on its first call, `wasm_init`: it now has an 8 MB stack, where its 1.2 MB runtime overflowed the default 1 MB (`D-042`).

### Changed
- The browser runtime takes its scenes from a host `Deck` table (`P32-04`, `D-042`). `zig build wasm` now builds `bespoke.wasm` with one neutral demo deck; the new `zig build wasm-proofs` builds `bespoke-proofs.wasm` with the six proof decks. Both export the same `wasm_*` functions. `WasmRuntime.init` takes a deck table and index, and `WasmScenario` and `load_scenario` are replaced by `load_deck`.
- Proof status, the portal guard rule, and save thumbnails no longer live in the engine (`P32-03`, `D-041`). A host passes its own status to its theme through `RenderFrame.host_status_bytes` and `DisplayBridge.set_status_hook`, draws HUD elements and overlays with `Theme.hud` and `Theme.overlay`, colours save thumbnails with a `ThumbnailPainter`, and names its player with `set_active_character` or `set_party`. A guarded actor reaches a portal through `Guarded` and `PassesGuard` facts. Removed: `RenderFrame`'s scenario fields, `DisplayBridge.set_tangent_countdown`, and `set_singularity_collapsed`. A save made with no scene now has an empty scene name instead of `Tavern`.
- Sound is supplied by the host (`P32-02d`, `D-040`): a `Soundtrack` of music tracks, sound effects as `SfxPatch` data, and a scene-to-track rule, registered with `AudioBridge.set_soundtrack` or a display `Theme`. The engine keeps only its interface and distaff sounds. `MusicTrackKind` is removed and tracks are referred to by index. A program without a soundtrack, including `bespoke run`, plays no music where it used to play the tavern theme; the proofs sound the same.
- Game keys are registered by the host (`P32-02c`, `D-039`): `Theme.keys` binds SDL keycodes to actions returned as `UserAction.custom`, checked before the engine's own letters. The engine no longer defines spitting-contest or conduit actions or binds `[S]`, `[H]`, `[G]`, `[F]`, and `[V]` itself. In the GK3 and Lochmarne Goat proofs a held key now acts once per press instead of every frame, and the goat proof's `[C]` no longer also opens the REPL.
- Presentation is now supplied by the host (`P32-02b`, `D-039`): a `Theme` of callbacks registered with `DisplayWindow.set_theme` draws backdrops, props, actor tokens, walkways, and footer hints, and the engine draws neutral defaults for anything a theme declines. A program that opens a window without a theme now gets a plain framed stage where it used to get the tavern backdrop. The proofs look the same; their art moved to `proofs/art.zig`.
- Cue dispatch no longer falls back to an unrelated handler (`P32-27`, `D-037`): a cue with no handler for its actor and target does nothing, where it used to run the first handler with that cue name. A handler parameter written in lowercase (`on cue Greets(visitor, Warden):`) matches any entity, `on cue X(Actor):` is that actor's default, and `on cue X():` is a compile error. Recompile `.bspk` packages that use variable parameters.
- Proof hygiene (`P32-19`): the Spitting Contest's placement is decided by its script (`on cue Spits(Guybrush):`); a spit now takes one tick. In the Day of the Tentacle and Middlesex Anomaly proofs, looking at something with no description of its own gives the active character's "Nothing unusual to see here." line; before, it repeated the first description in the script.
- `.bspk` packages are now format version 3, which adds the arrival edge to reactive rules; versions 1 and 2 still load (`D-036`).
- In the interactive Lochmarne Goat proof, a knocked-down George walks back to the fall mark instead of snapping there, clicking the ladder while standing on it climbs out, and George no longer drops back into the crypt on the tick after climbing out.
- Dialogue duels and inquiry fatigue are now an engine module, `src/duel.zig` (`P32-17`, `D-035`): a host supplies challenge/reply pairs with optional tier variants and a ladder of mood stages; `Duel` offers a fighter's known lines as fact-guarded dialogue choices, resolves rounds, teaches replies on a failed answer, and tracks advantage and wins; `InquiryFatigue` counts inquiries per speaker and NPC and asserts moods that decay with the tick clock. Insult Sword Fighting is now a client of it with an unchanged headless transcript. Pestering one NPC no longer tires every other NPC.
- Emergent society simulation is now an engine module, `src/society.zig` (`P32-05`, `D-034`): a host configures any roster, list of needs (each met by resting at a place or trading with a merchant, with theft past a critical value), data roles (merchant, broadcaster, enforcer), routines, and places, and `Society.step` runs drives, witnesses, rumors, and justice over World facts. The Living Village is now a client of it with an unchanged headless transcript. In the interactive village, grudges now expire after 60 and 50 ticks as intended (previously later), the Gossip and Drifter return to Socializing after a meal, and an arrest after a tip-off without a theft no longer claims to recover bread.

Every proof now uses it. Interactive time travel works the same in every proof (scrub keeps the future until the clock advances); DOTT, The Middlesex Anomaly, and Insult Sword Fighting gain shared save actions; Insult Sword Fighting now ticks at the standard interval instead of every frame. Fixed speech readers that dropped scripted dialogue after the first line of a run.
